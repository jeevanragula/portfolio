# Contributing

This is a personal portfolio and Career OS project. Changes should preserve factual accuracy and the existing design language.

## Before Changes

Understand:

- `data/career.json` — career source of truth
- `index.html` — page structure
- `index.css` — visual system
- `app.js` — rendering and interactions

Read [ARCHITECTURE.md](ARCHITECTURE.md) before structural changes.

## Content

Career facts should normally be changed only in `data/career.json`. Do not create conflicting copies of the same fact.

## Design

Preserve the existing visual identity unless a redesign is explicitly requested. Avoid unnecessary frameworks, breaking responsive behavior, or removing existing interactions.

## Commit Messages

Use concise messages such as:

```text
career: update current designation
career: add patent
career: add product architecture
ui: fix mobile timeline
docs: update architecture
fix: correct portfolio link
```

## Accuracy

Do not invent achievements, responsibilities, metrics, titles, or dates. Career information should be explicitly provided or verified by Jeevan Reddy Ragula.
